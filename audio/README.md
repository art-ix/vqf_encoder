# Sample VQF files

These files are provided so the decoder can be tested without hunting for TwinVQ audio.

They were downloaded from the public SoundVQ / VQF sample page:

- <http://www.onlovestar.com/noise/vqf.htm>

| File | Notes |
| --- | --- |
| `koshuks-40kb.vqf` | *(Walk Among) Koshuks* — stereo, 40 kbit/s |
| `koshuks-96kb.vqf` | *(Walk Among) Koshuks* — 96 kbit/s |

The recording is credited on that site to **institut für universelle zusammenhänge**. The files are redistributed here only as decoder test material. Copyright remains with the original authors / site. If you are a rights holder and want them removed, open an issue.

Do not add commercially released albums to this folder.
